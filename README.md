# 🏛️ OurBank - Tabungan Bersama

Aplikasi web sederhana untuk mencatat dan memantau tabungan bersama secara *real-time* antara 2 pengguna.

## 🚀 Fitur Utama
* **Sistem Login PIN:** Akses cepat dan mudah menggunakan nama & PIN sederhana.
* **Ringkasan Saldo:** Menampilkan total saldo terkumpul dan total setoran minggu ini.
* **Progress Target:** Visualisasi persentase pencapaian target tabungan (*progress bar*).
* **Riwayat Transaksi Real-time:** Pencatatan nama penabung, nominal, catatan, dan tanggal setoran yang otomatis tersinkronisasi antar perangkat.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Database:** Firebase Realtime Database
* **Hosting:** Vercel / GitHub Pages
